Escolas e licenças

O administrador full cadastra a escola e libera a licença. Em cada licença você define se vale para o Acompanha Aí, o Minha Vez e/ou o MatrixEdu. Sem licença ativa daquele sistema, a escola não entra.

Ligação com o Minha Vez

Cole a URL e o token da API do Minha Vez (os mesmos de api/ativar.php daquele site). Usuários, senhas e alunos da escola com licença Minha Vez são enviados automaticamente para lá.

Ligação com o MatrixEdu

Cole a URL e o token da API do MatrixEdu (os mesmos de api/ativar.php daquele site). Usuários e senhas da escola com licença MatrixEdu são enviados automaticamente para lá.

Hostinger

Tudo é automático. Ao cadastrar aluno, usuário ou ocorrência, o sistema grava sozinho no MySQL da Hostinger. O site e os dados ficam no mesmo servidor. Os outros computadores atualizam sozinhos em poucos segundos.

Procurando servidor da escola…

Status verde = sincronização automática ativa. Site e API na Hostinger: pasta api/ + api/ativar.php.

Ferramentas de emergência (opcional)

No dia a dia não precisa usar isto. Só se um PC ficou desatualizado ou a base precisa ser republicada.

E-mail automático (EmailJS + Outlook)

Ao registrar uma ocorrência com e-mail do responsável, o sistema envia automaticamente um aviso pela conta Outlook conectada no EmailJS.

E-mail não configurado
  1. Crie conta em emailjs.com.
  2. Email Services → Add Service → Outlook / Office 365 e conecte a conta da escola.
  3. Email Templates → Create Template com as variáveis abaixo.
  4. Cole Public Key, Service ID e Template ID e salve.
Variáveis do template

Use no EmailJS (To Email = {{to_email}}):

to_email, to_name, subject, protocolo, nivel, data, aluno, ra, turma, tutor, tipo, descricao, resumo, message

O campo {{message}} (e {{resumo}}) já vem com o comunicado padrão à família: saudação, resumo da ocorrência e providências.

Log de segurança

Registro automático das ações no sistema (login, cadastros, edições e exclusões). Senhas nunca são gravadas.
