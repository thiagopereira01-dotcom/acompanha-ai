    Nuvem gratuita

    Configure a nuvem uma única vez. Depois de fixar o código no sistema e publicar no Render, professores e demais PCs sincronizam sozinhos — sem entrar como admin em cada máquina.

    Nuvem não configurada
    1. Clique em Criar nuvem e copie o código.
    2. No arquivo index.html, cole o código em CLOUD_BLOB_ID_FIXO (perto do topo do JavaScript).
    3. Publique de novo no Render. Pronto: todos os PCs usam a mesma base automaticamente.

    E-mail automático (EmailJS + Outlook)

    Ao registrar uma ocorrência com e-mail do responsável, o sistema envia automaticamente um aviso pela conta Outlook conectada no EmailJS.

    E-mail não configurado
    1. Crie conta em emailjs.com.
    2. Email Services → Add Service → Outlook / Office 365 e conecte a conta da escola.
    3. Email Templates → Create Template com as variáveis abaixo.
    4. Cole Public Key, Service ID e Template ID e salve.
    Variáveis do template

    Use no EmailJS (To Email = {{to_email}}):

    to_email, to_name, subject, protocolo, nivel, data, professor, aluno, ra, turma, tutor, tipo, descricao, message
